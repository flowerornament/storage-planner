## Tech Debt

### Critical (known issues, not blocking requirements)

**Undo/Redo System Limitations:**
- BUG-01: Undo of `.updated` events uses delete+insert pattern which cascades children
- BUG-02: Undo of `.deleted` events doesn't restore cascaded children
- BUG-03: parent_id FK fixed (ON DELETE SET NULL added in fix(08)), but core pattern still problematic
- UNDO-01: Redo fails for import and multi-entity creation events
- UNDO-02: No way to skip past a failed undo event

> Note: The undo/redo system works for simple cases but has edge cases with cascaded FK relationships. The core functionality (topology CRUD, analysis, decisions, catalog) is unaffected. This is tracked for v2.

### Medium

**Prime Guide Accuracy:**
- 5 remaining command syntax errors in `sp prime` static guide (PRIME-01 through PRIME-05)
- Some were partially addressed in fix(09) but not all confirmed fixed
