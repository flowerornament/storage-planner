  <files>src/core/db.rs, src/core/models.rs</files>
  <action>
**In src/core/db.rs:**

1. Bump `CURRENT_VERSION` from 1 to 2.
2. Add Migration v2 to the `MIGRATIONS` array with this SQL:

```sql
ALTER TABLE topologies ADD COLUMN tag TEXT DEFAULT NULL;
UPDATE topologies SET tag = 'current' WHERE is_active = 1;
ALTER TABLE topologies DROP COLUMN is_active;
CREATE UNIQUE INDEX idx_topologies_current ON topologies(tag) WHERE tag = 'current';
PRAGMA user_version = 2;
```

The partial unique index `WHERE tag = 'current'` enforces at the database level that only one topology can be tagged "current". This is stronger than application-level enforcement.

Note: `ALTER TABLE ... DROP COLUMN` requires SQLite 3.35.0+. The bundled SQLite in rusqlite 0.31 is 3.45+, so this is safe.

3. Update the test `test_tables_exist` if needed (table list unchanged, just column changes).
4. Add a new test `test_migration_v2_tag_column` that:
   - Creates a v1 database manually (insert topology with is_active=1)
   - Runs migration
   - Verifies the tag column exists with value 'current'
   - Verifies the partial unique index prevents two 'current' tags

**In src/core/models.rs:**

1. Replace the `is_active: bool` field on `Topology` with `tag: Option<String>`.
2. Update `Topology::new()`: set `tag: None` instead of `is_active: false`.
3. Update `Topology::insert()`: change the INSERT statement to use `tag` column instead of `is_active`. Write `self.tag` directly (it's Option<String>, rusqlite handles NULL).
4. Update `Topology::from_row()`: read `tag: row.get("tag")?` instead of `is_active: row.get::<_, i32>("is_active")? != 0`.
