  <name>Task 1: Rewrite Database migration system with PRAGMA user_version and full Phase 1 schema</name>
  <files>src/core/db.rs</files>
  <action>
Rewrite the migration system in `src/core/db.rs`:

1. **Add migration infrastructure** above the existing `SCHEMA` constant:
   - Define a `Migration` struct with `version: i32` and `sql: &'static str` fields.
   - Define a `const MIGRATIONS: &[Migration]` array. For Phase 1, there is ONE migration at version 1.
   - Keep the existing `SCHEMA` constant renamed to `LEGACY_SCHEMA` (it creates items, prices, configurations, decisions, old events, and FTS tables).

2. **Rewrite `Database::migrate()`** to use versioned migrations:
   - Read current version: `self.conn.pragma_query_value(None, "user_version", |row| row.get(0))?`
   - If version is 0: Apply `LEGACY_SCHEMA` first (idempotent `CREATE TABLE IF NOT EXISTS`), then apply all MIGRATIONS with version > 0.
   - For each migration where `migration.version > current_version`: Execute `migration.sql` in a transaction, then set `PRAGMA user_version = {version}`.
   - This preserves existing tables (items, prices, configs, decisions) while adding new topology tables.

3. **Phase 1 migration SQL** (version 1) must create ALL of these tables exactly as specified:

   ```sql
   -- Topology tables (7 new tables)
   CREATE TABLE topologies (
       id TEXT PRIMARY KEY,
       name TEXT NOT NULL UNIQUE,
       description TEXT NOT NULL DEFAULT '',
       parent_id TEXT REFERENCES topologies(id),
       is_active INTEGER NOT NULL DEFAULT 0,
       created_at TEXT NOT NULL DEFAULT (datetime('now')),
       updated_at TEXT NOT NULL DEFAULT (datetime('now'))
   );

   CREATE TABLE nodes (
       id TEXT PRIMARY KEY,
       topology_id TEXT NOT NULL REFERENCES topologies(id) ON DELETE CASCADE,
       name TEXT NOT NULL,
       role TEXT NOT NULL,
       location TEXT NOT NULL DEFAULT '',
       available_bays INTEGER,
       interface_types TEXT NOT NULL DEFAULT '',
       power_draw_watts REAL,
       created_at TEXT NOT NULL DEFAULT (datetime('now')),
       updated_at TEXT NOT NULL DEFAULT (datetime('now')),
       UNIQUE(topology_id, name)
   );

   CREATE TABLE volumes (
       id TEXT PRIMARY KEY,
       topology_id TEXT NOT NULL REFERENCES topologies(id) ON DELETE CASCADE,
       node_id TEXT NOT NULL REFERENCES nodes(id) ON DELETE CASCADE,
       name TEXT NOT NULL,
       capacity_bytes INTEGER NOT NULL,
       usable_bytes INTEGER,
       filesystem TEXT,
       raid_level TEXT,
       pool_type TEXT,
       item_id TEXT REFERENCES items(id),
       created_at TEXT NOT NULL DEFAULT (datetime('now')),
       updated_at TEXT NOT NULL DEFAULT (datetime('now')),
       UNIQUE(topology_id, node_id, name)
   );

   CREATE TABLE datasets (
       id TEXT PRIMARY KEY,
       topology_id TEXT NOT NULL REFERENCES topologies(id) ON DELETE CASCADE,
       name TEXT NOT NULL,
       size_bytes INTEGER NOT NULL,
       growth_rate_bytes_month REAL,
       criticality TEXT NOT NULL DEFAULT 'normal',
       min_copies INTEGER NOT NULL DEFAULT 1,
       min_locations INTEGER NOT NULL DEFAULT 1,
       max_rpo_hours INTEGER,
       created_at TEXT NOT NULL DEFAULT (datetime('now')),
       updated_at TEXT NOT NULL DEFAULT (datetime('now')),
       UNIQUE(topology_id, name)
   );

   CREATE TABLE placements (
       id TEXT PRIMARY KEY,
       topology_id TEXT NOT NULL REFERENCES topologies(id) ON DELETE CASCADE,
       dataset_id TEXT NOT NULL REFERENCES datasets(id) ON DELETE CASCADE,
       volume_id TEXT NOT NULL REFERENCES volumes(id) ON DELETE CASCADE,
       role TEXT NOT NULL DEFAULT 'primary',
       priority INTEGER NOT NULL DEFAULT 0,
       created_at TEXT NOT NULL DEFAULT (datetime('now')),
       UNIQUE(dataset_id, volume_id)
   );

   CREATE TABLE links (
       id TEXT PRIMARY KEY,
       topology_id TEXT NOT NULL REFERENCES topologies(id) ON DELETE CASCADE,
       source_node_id TEXT NOT NULL REFERENCES nodes(id) ON DELETE CASCADE,
       target_node_id TEXT NOT NULL REFERENCES nodes(id) ON DELETE CASCADE,
       bandwidth_bytes_sec INTEGER,
       connection_type TEXT NOT NULL,
       latency_ms REAL,
       is_metered INTEGER NOT NULL DEFAULT 0,
       cost_per_gb_cents INTEGER,
       created_at TEXT NOT NULL DEFAULT (datetime('now')),
       updated_at TEXT NOT NULL DEFAULT (datetime('now')),
       UNIQUE(topology_id, source_node_id, target_node_id)
   );

   CREATE TABLE sync_regimes (
       id TEXT PRIMARY KEY,
       topology_id TEXT NOT NULL REFERENCES topologies(id) ON DELETE CASCADE,
       name TEXT NOT NULL,
       dataset_id TEXT NOT NULL REFERENCES datasets(id) ON DELETE CASCADE,
       source_volume_id TEXT NOT NULL REFERENCES volumes(id) ON DELETE CASCADE,
       target_volume_id TEXT NOT NULL REFERENCES volumes(id) ON DELETE CASCADE,
       sync_type TEXT NOT NULL,
       schedule TEXT,
       direction TEXT NOT NULL DEFAULT 'push',
       created_at TEXT NOT NULL DEFAULT (datetime('now')),
       updated_at TEXT NOT NULL DEFAULT (datetime('now')),
       UNIQUE(topology_id, name)
   );
   ```

   The migration must also DROP the old events table and CREATE the redesigned one:
   ```sql
   DROP TABLE IF EXISTS events;

   CREATE TABLE events (
       id TEXT PRIMARY KEY,
       sequence INTEGER NOT NULL UNIQUE,
       event_type TEXT NOT NULL,
       entity_type TEXT NOT NULL,
       entity_id TEXT NOT NULL,
       summary TEXT NOT NULL,
       before_state TEXT,
       after_state TEXT,
       source TEXT NOT NULL DEFAULT 'user',
       actor TEXT NOT NULL DEFAULT 'unknown',
       timestamp TEXT NOT NULL DEFAULT (datetime('now'))
   );

   CREATE INDEX idx_events_sequence ON events(sequence);
   CREATE INDEX idx_events_entity ON events(entity_type, entity_id);
   CREATE INDEX idx_events_timestamp ON events(timestamp);

   CREATE TABLE undo_pointer (
       id INTEGER PRIMARY KEY CHECK (id = 1),
       current_sequence INTEGER NOT NULL DEFAULT 0
   );
   INSERT INTO undo_pointer (id, current_sequence) VALUES (1, 0);
   ```

   Plus all indexes for topology tables (idx_nodes_topology, idx_volumes_topology, idx_volumes_node, idx_datasets_topology, idx_placements_dataset, idx_placements_volume, idx_links_topology, idx_sync_regimes_topology, idx_sync_regimes_dataset).

   End the migration SQL with: `PRAGMA user_version = 1;`

4. **Update `Database::is_initialized()`** to also check for the topologies table (so it detects Phase 1+ schemas).

5. **Update `Database::stats()`** to include topology counts (topologies, nodes, volumes, datasets). Use separate query_row calls like the existing pattern. Add the new fields to `DbStats`.

   - Add `test_migration_idempotent`: Calling migrate twice should not error
   - Add `test_migration_preserves_existing`: Insert item before migration, verify item still exists after

**CRITICAL constraints (from locked decisions):**
- Strictly typed columns -- NO JSON metadata blobs on new tables
- Fresh start OK -- the migration can drop the old events table
- Keep existing tables (items, prices, configurations, decisions) -- they serve catalog/pricing functionality and `volumes.item_id` references `items(id)`
- ON DELETE CASCADE for topology->child relationships

  <name>Task 2: Create topology entity model structs with new/insert/from_row</name>
  <files>src/domains/storage/models.rs, src/domains/storage/mod.rs</files>

**Completely rewrite** `src/domains/storage/models.rs` with database-backed model structs for all 7 topology entities. Follow the exact patterns in `src/core/models.rs` (Item, Price, Configuration):
- `#[derive(Debug, Clone, Serialize, Deserialize)]`
- `new()` constructor with required fields, auto-generates UUID v4 id and timestamps
- `insert(&self, tx: &Transaction) -> rusqlite::Result<()>` using `params![]`
- `from_row(row: &Row) -> rusqlite::Result<Self>` using named column access

**Topology:**
- Fields: id (String), name (String), description (String), parent_id (Option<String>), is_active (bool), created_at (DateTime<Utc>), updated_at (DateTime<Utc>)
- `new(name, description)` -- generates UUID, sets is_active=false, timestamps=now

**Node:**
- Fields: id, topology_id, name, role (String -- "desktop", "nas", "server", "cloud", "external"), location, available_bays (Option<i32>), interface_types (String -- comma-separated), power_draw_watts (Option<f64>), created_at, updated_at
- `new(topology_id, name, role)` -- generates UUID, defaults: location="", interface_types="", bays/power=None

**Volume:**
- Fields: id, topology_id, node_id, name, capacity_bytes (i64), usable_bytes (Option<i64>), filesystem (Option<String>), raid_level (Option<String>), pool_type (Option<String>), item_id (Option<String>), created_at, updated_at
- `new(topology_id, node_id, name, capacity_bytes)` -- generates UUID, optional fields=None

**Dataset:**
- Fields: id, topology_id, name, size_bytes (i64), growth_rate_bytes_month (Option<f64>), criticality (String -- default "normal"), min_copies (i32 -- default 1), min_locations (i32 -- default 1), max_rpo_hours (Option<i32>), created_at, updated_at
- `new(topology_id, name, size_bytes)` -- generates UUID, defaults as above

**Placement:**
- Fields: id, topology_id, dataset_id, volume_id, role (String -- default "primary"), priority (i32 -- default 0), created_at
- `new(topology_id, dataset_id, volume_id)` -- generates UUID, defaults as above
- NOTE: No updated_at (placements are created/deleted, not updated)

**Link:**
- Fields: id, topology_id, source_node_id, target_node_id, bandwidth_bytes_sec (Option<i64>), connection_type (String), latency_ms (Option<f64>), is_metered (bool -- default false), cost_per_gb_cents (Option<i32>), created_at, updated_at
- `new(topology_id, source_node_id, target_node_id, connection_type)` -- generates UUID, optional fields=None/false

**SyncRegime:**
- Fields: id, topology_id, name, dataset_id, source_volume_id, target_volume_id, sync_type (String), schedule (Option<String>), direction (String -- default "push"), created_at, updated_at
- `new(topology_id, name, dataset_id, source_volume_id, target_volume_id, sync_type)` -- generates UUID

**Ensure `src/domains/storage/mod.rs` exports the models module** (it likely already does, verify).

**Add round-trip tests** at the bottom of models.rs:
- Test each model: create with new(), insert into test DB (use Database::open_memory() + migrate()), then SELECT back and verify via from_row().
- Test at minimum: Topology and Node (most complex). Other models follow the same pattern.
- Test the foreign key: insert Topology first, then Node with that topology_id.
- Test UNIQUE constraint: inserting two nodes with same (topology_id, name) should fail.

**CRITICAL constraints:**
- Strictly typed columns: every field is a concrete Rust type, no JsonValue on topology models
- Use i64 for byte-sized fields (capacity_bytes, usable_bytes, bandwidth_bytes_sec) -- SQLite INTEGER is 64-bit
- Use String for enum-like fields (role, criticality, sync_type, connection_type, direction) -- parse validation will come in Phase 2 CLI commands
- Store booleans as i32 in SQLite (0/1), convert in from_row()
