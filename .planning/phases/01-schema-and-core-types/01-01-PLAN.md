WRITE src/core/db.rs from scratch. This is the critical infrastructure piece.

Database struct wraps rusqlite::Connection:
- `path: PathBuf` field (use std::path::PathBuf, not camino)
- `open(path: &Path) -> Result<Self>` — creates parent dir, opens connection, sets PRAGMAs (foreign_keys=ON, journal_mode=WAL, synchronous=NORMAL), runs migrate()
- `open_memory() -> Result<Self>` — for testing, sets foreign_keys=ON, runs migrate()
- `transaction<T, F>(&mut self, f: F) -> Result<T>` — same pattern as existing
- `conn(&self) -> &Connection` and `conn_mut(&mut self) -> &mut Connection`
- `migrate(&mut self) -> Result<()>` — PRAGMA user_version migration system

Migration system design:
```rust
const CURRENT_VERSION: i32 = 1;

struct Migration {
    version: i32,
    sql: &'static str,
}

const MIGRATIONS: &[Migration] = &[
    Migration { version: 1, sql: SCHEMA_V1 },
];
```

`migrate()` reads current version via `PRAGMA user_version`, then applies any migrations with version > current in order. Each migration SQL ends with `PRAGMA user_version = N;`

SCHEMA_V1 contains ALL tables (copy the DDL from the research document's "Migration Schema Pattern" section), with ONE CRITICAL CHANGE:
- volumes.item_id must be `TEXT` with NO REFERENCES clause (the items table does not exist in the rewrite). Comment it: `-- FK added in Phase 6 when catalog is ported`

The full schema includes:
- topologies (id, name, description, parent_id, is_active, created_at, updated_at)
- nodes (id, topology_id, name, role, location, available_bays, interface_types, power_draw_watts, created_at, updated_at) with UNIQUE(topology_id, name)
- volumes (id, topology_id, node_id, name, capacity_bytes, usable_bytes, filesystem, raid_level, pool_type, item_id TEXT, created_at, updated_at) with UNIQUE(topology_id, node_id, name)
- datasets (id, topology_id, name, size_bytes, growth_rate_bytes_month, criticality, min_copies, min_locations, max_rpo_hours, created_at, updated_at) with UNIQUE(topology_id, name)
- placements (id, topology_id, dataset_id, volume_id, role, priority, created_at) with UNIQUE(dataset_id, volume_id)
- links (id, topology_id, source_node_id, target_node_id, bandwidth_bytes_sec, connection_type, latency_ms, is_metered, cost_per_gb_cents, created_at, updated_at) with UNIQUE(topology_id, source_node_id, target_node_id)
- sync_regimes (id, topology_id, name, dataset_id, source_volume_id, target_volume_id, sync_type, schedule, direction, created_at, updated_at) with UNIQUE(topology_id, name)
- events (id, sequence, event_type, entity_type, entity_id, summary, before_state, after_state, source, actor, timestamp) with indexes on sequence, entity, timestamp
- undo_pointer (id INTEGER PRIMARY KEY CHECK(id=1), current_sequence INTEGER NOT NULL DEFAULT 0) with initial row INSERT

All topology child tables use `ON DELETE CASCADE` referencing their parent. nodes/volumes/datasets/links/sync_regimes reference topologies(id) ON DELETE CASCADE. volumes also reference nodes(id) ON DELETE CASCADE. placements reference datasets(id) and volumes(id) ON DELETE CASCADE. sync_regimes reference datasets(id), source/target volumes ON DELETE CASCADE.

Add indexes matching the research: idx_nodes_topology, idx_volumes_topology, idx_volumes_node, idx_datasets_topology, idx_placements_dataset, idx_placements_volume, idx_links_topology, idx_sync_regimes_topology, idx_sync_regimes_dataset.

WRITE src/core/models.rs with model structs for ALL 7 topology entities plus Event. Each struct follows the established pattern: `#[derive(Debug, Clone, Serialize, Deserialize)]` with these methods:
- `new(...)` — creates with UUID id and current timestamps
- `insert(&self, tx: &Transaction) -> Result<()>` — INSERT using params![]
- `from_row(row: &Row) -> rusqlite::Result<Self>` — reads from named columns
- `to_json(&self) -> Result<String>` — serializes to JSON (for event before/after state)

Entity structs and their fields (match the DDL exactly):

**Topology**: id, name, description, parent_id (Option), is_active (bool), created_at, updated_at
- `new(name, description)` — is_active defaults to false

**Node**: id, topology_id, name, role, location, available_bays (Option<i32>), interface_types, power_draw_watts (Option<f64>), created_at, updated_at
- `new(topology_id, name, role)` — location defaults to empty string, interface_types to empty string

**Volume**: id, topology_id, node_id, name, capacity_bytes (i64), usable_bytes (Option<i64>), filesystem (Option<String>), raid_level (Option<String>), pool_type (Option<String>), item_id (Option<String>), created_at, updated_at
- `new(topology_id, node_id, name, capacity_bytes)`

**Dataset**: id, topology_id, name, size_bytes (i64), growth_rate_bytes_month (Option<f64>), criticality, min_copies (i32), min_locations (i32), max_rpo_hours (Option<i32>), created_at, updated_at
- `new(topology_id, name, size_bytes)` — criticality defaults to "normal", min_copies/min_locations to 1

**Placement**: id, topology_id, dataset_id, volume_id, role, priority (i32), created_at
- `new(topology_id, dataset_id, volume_id)` — role defaults to "primary", priority to 0
- Note: placements have no updated_at (immutable junction — delete and recreate to change)

**Link**: id, topology_id, source_node_id, target_node_id, bandwidth_bytes_sec (Option<i64>), connection_type, latency_ms (Option<f64>), is_metered (bool), cost_per_gb_cents (Option<i32>), created_at, updated_at
- `new(topology_id, source_node_id, target_node_id, connection_type)`

**SyncRegime**: id, topology_id, name, dataset_id, source_volume_id, target_volume_id, sync_type, schedule (Option<String>), direction, created_at, updated_at
- `new(topology_id, name, dataset_id, source_volume_id, target_volume_id, sync_type)` — direction defaults to "push"

For DateTime handling: Store as RFC3339 strings in SQLite. Parse back with DateTime::parse_from_rfc3339. Use `chrono::Utc::now()` for timestamps.

For booleans (is_active, is_metered): Store as INTEGER (0/1) in SQLite, convert in from_row/insert.

For to_json: Use `serde_json::to_string(self)?` — all structs derive Serialize.
