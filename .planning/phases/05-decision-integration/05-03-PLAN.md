```rust
#[derive(Debug, Clone, Serialize, Deserialize, PartialEq)]
pub enum ConstraintStatus {
    Pass,
    Warn,
    Fail,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ConstraintResult {
    pub constraint_type: String,
    pub limit: f64,
    pub actual: f64,
    pub status: ConstraintStatus,
    pub margin: f64,       // positive = headroom, negative = overage
    pub margin_pct: f64,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ConstraintReport {
    pub score: f64,
    pub results: Vec<ConstraintResult>,
    pub has_failures: bool,
}
```

Implement Display for ConstraintStatus: "PASS", "WARN", "FAIL".

**check_constraints function:**
```rust
pub fn check_constraints(
    constraints: &[DecisionConstraint],
    nodes: &[Node],
) -> ConstraintReport
```
- For each constraint, sum across nodes based on constraint_type:
  - "budget" => sum nodes.cost_estimate (filter_map on Option)
  - "noise" => sum nodes.noise_db (filter_map on Option)
  - "power" => sum nodes.power_draw_watts (filter_map on Option)  -- NOTE: use existing power_draw_watts field, NOT a new field
  - "rack_units" => sum nodes.rack_units (filter_map on Option)
- Status logic (per user decision):
  - actual > limit => Fail
  - actual > limit * 0.9 => Warn
  - else => Pass
- margin = limit - actual (positive = headroom, negative = overage)
- margin_pct = (margin / limit) * 100.0 (guard against limit=0)
- score = (passing_count / total_count) * 100.0 (100.0 if no constraints)
- has_failures = any Fail status

```rust
pub struct TopologyMetrics {
    pub name: String,
    pub id: String,
    pub node_count: usize,
    pub volume_count: usize,
    pub total_capacity_bytes: i64,
    pub total_usable_bytes: i64,

    pub total_rack_units: f64,
    pub redundancy_score: f64,
    pub capacity_score: f64,
    pub rpo_score: f64,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct MetricComparison {
    pub metric: String,
    pub a: f64,
    pub b: f64,
    pub better: String,  // "a", "b", or "tie"
    pub unit: String,
}

#[derive(Debug, Clone, Serialize, Deserialize)]
pub struct ComparisonReport {
    pub topology_a: TopologyMetrics,
    pub topology_b: TopologyMetrics,
    pub metrics_comparison: Vec<MetricComparison>,
    pub constraints_a: Option<ConstraintReport>,
    pub constraints_b: Option<ConstraintReport>,
}
```

**compute_topology_metrics function:**
```rust
pub fn compute_topology_metrics(
    name: &str,
    id: &str,
    nodes: &[Node],
    volumes: &[Volume],
    datasets: &[Dataset],
    placements: &[PlacementWithContext],
    sync_regimes: &[SyncRegimeWithContext],
    warn_months: i32,
) -> TopologyMetrics
```
- node_count = nodes.len()
- volume_count = volumes.len()
- total_capacity_bytes = sum of volume.capacity_bytes
- total_usable_bytes = sum of volume.usable_bytes.unwrap_or(volume.capacity_bytes)
- dataset_count = datasets.len()
- total_cost_estimate = sum of node.cost_estimate (filter_map)
- total_noise_db = sum of node.noise_db (filter_map)
- total_power_watts = sum of node.power_draw_watts (filter_map)
- total_rack_units = sum of node.rack_units (filter_map)
- redundancy_score = analyze_redundancy(datasets, placements).score
- capacity_score = analyze_capacity(datasets, volumes, placements, warn_months).score
- rpo_score = analyze_rpo(datasets, placements, sync_regimes).score

**compare_topologies function:**

```rust
pub fn compare_topologies(
```

- Build metrics_comparison Vec<MetricComparison> for each comparable metric:
  - "total_cost" (unit: "$", lower is better)
  - "total_noise" (unit: "dB", lower is better)
  - "total_power" (unit: "W", lower is better)
  - "total_rack_units" (unit: "U", lower is better)
  - "total_capacity" (unit: "bytes", higher is better)
  - "total_usable" (unit: "bytes", higher is better)
  - "redundancy" (unit: "%", higher is better)
  - "capacity" (unit: "%", higher is better)
  - "rpo" (unit: "%", higher is better)
  - "nodes" (unit: "", neutral -- no better)
  - "volumes" (unit: "", neutral)
  - "datasets" (unit: "", neutral)
- For "better": compare a vs b. If equal, "tie". For lower-is-better: a < b => "a". For higher-is-better: a > b => "a".

**choose() function (DEC-09):**
1. resolve_decision + resolve_topology.
2. Validate state machine: decision.status must be "open". Bail if not: "Cannot choose for decision in '{status}' state (must be 'open')".
3. Validate the topology is being considered: `SELECT COUNT(*) FROM decision_topologies WHERE decision_id = ?1 AND topology_id = ?2`. Bail if not: "Topology '{name}' is not being considered for this decision".
4. Generate snapshot JSON blob:
   - Load constraints for the decision
   - For each considered topology: load nodes, volumes, datasets, placements, sync regimes. Call compute_topology_metrics. If constraints exist, call check_constraints.
   - Build snapshot JSON: `{ "considered_topologies": [ { "name": ..., "metrics": {...}, "constraints": {...} }, ... ] }`
   - Serialize to string.
5. Build before_state from current decision.
6. In transaction:
   - `UPDATE decisions SET status = 'decided', chosen_topology_id = ?1, rationale = ?2, snapshot = ?3, closed_at = datetime('now'), updated_at = datetime('now') WHERE id = ?4`
   - record_event("decision.updated", "decision", ..., before_state, after_state)
7. Text: `Decided: '{title}' -- chose topology '{topo_name}'`. JSON output with full decision.

**abandon() function (DEC-10):**
1. resolve_decision.
2. Validate: status must be "draft" or "open". Bail if "decided" or "abandoned".
3. Generate snapshot (same as choose but no chosen topology).
4. In transaction:
   - `UPDATE decisions SET status = 'abandoned', rationale = ?1, snapshot = ?2, closed_at = datetime('now'), updated_at = datetime('now') WHERE id = ?3`
   - record_event with before/after.
5. Text: `Abandoned decision '{title}'`.

**reopen() function (DEC-11):**
1. resolve_decision.
2. Validate: status must be "decided" or "abandoned". Bail if "draft" or "open": "Decision is already open/draft".
3. In transaction:
   - `UPDATE decisions SET status = 'open', chosen_topology_id = NULL, rationale = NULL, updated_at = datetime('now') WHERE id = ?1`
   - Note: keep snapshot as historical record, keep constraints and considered topologies intact, clear closed_at too: `closed_at = NULL`
   - record_event with before/after.
4. Text: `Reopened decision '{title}'`.

**run_constraints() function (ANLZ-02):**
1. Resolve decision with resolve_decision.
2. Load decision constraints from DB.
3. Resolve topology (from --topology flag or active).
4. Load nodes for that topology.
5. Call check_constraints(constraints, nodes).
6. Text output -- follow the pass/warn/fail analysis header pattern:
   ```
   Constraints: {score}% ({n} checked)

     [PASS] budget:     $750.00 / $1000.00 max   ($250.00 headroom, 25.0%)
     [WARN] noise:      29.5 dB / 32.0 dB max    (2.5 dB headroom, 7.8%)
     [FAIL] rack_units: 6.0 U / 4.0 U max        (2.0 U over, -50.0%)
   ```
   Use console colors: green for PASS, yellow for WARN, red for FAIL.
   Format units based on constraint_type: $ for budget, dB for noise, W for power, U for rack_units.
7. JSON output: `{ "topology": ..., "decision": ..., "analysis": "constraints", "report": constraint_report }`.
8. Exit code 1 if any failures (following D028 pattern).

**run_compare() function (ANLZ-08):**
1. Resolve both topologies by name or ID.
2. For each topology: load nodes, volumes, datasets, placements, sync regimes. Call compute_topology_metrics.
3. If --decision provided: resolve decision, load constraints, call check_constraints for each topology.
4. Call compare_topologies(metrics_a, metrics_b, constraints_a, constraints_b).
5. Text output:
   ```
   Comparison: {topo_a_name} vs {topo_b_name}

     Metric            {topo_a_name}    {topo_b_name}    Better
     -------           ---------        ---------        ------
     Total cost        $850.00          $1,200.00        <- A
     Total noise       0.0 dB           32.0 dB          <- A
     Total power       39.0 W           65.0 W           <- A
     Total capacity    8.0 TB           16.0 TB          <- B
     Redundancy        100.0%           75.0%            <- A
     Capacity          100.0%           50.0%            <- A
     RPO               100.0%           100.0%           tie
   ```
   If constraints provided, append constraint results for each topology below the comparison table.
6. If --diff flag, call the existing diff engine (from topology.rs diff command pattern) and append structural diff output.
7. JSON output: ComparisonReport including optional diff field.
