**Create src/cli/decision.rs** with DecisionCommands enum and run() function. Follow the exact pattern from topology.rs and node.rs.

**DecisionCommands enum** (clap derive):
```
Create { title: String, #[arg(long, default_value = "")] description: String, #[arg(long)] parent: Option<String> }
Show { decision: String }
List { #[arg(long)] status: Option<String> }
Update { decision: String, #[arg(long)] title: Option<String>, #[arg(long)] description: Option<String>, #[arg(long)] open: bool }
Constrain { decision: String, #[arg(long, value_name = "TYPE")] r#type: String, #[arg(long)] max: f64 }
Unconstrain { decision: String, #[arg(long, value_name = "TYPE")] r#type: String }
Consider { decision: String, topology: String }
Unconsider { decision: String, topology: String }
Choose { decision: String, topology: String, #[arg(long)] rationale: String }
Abandon { decision: String, #[arg(long)] reason: Option<String> }
Reopen { decision: String }
```

Note: Choose, Abandon, Reopen are declared in the enum here for CLI structure but their handler implementations will be stubs that bail!("not yet implemented") -- Plan 03 implements the full logic.

**run() function:** Match on DecisionCommands, dispatch to implementation functions.

**create() function (DEC-01):**
1. If parent is provided, resolve it with resolve_decision (validates it exists).
2. Create Decision::new(title), set description, set parent_id if parent provided.
3. Insert in transaction with record_event("decision.created", "decision", ...).
4. Text output: `Created decision '{title}' (id: {id_prefix})`.
5. JSON output: `{ "action": "created", "decision": title, "id": id, "status": "draft" }`.

**show() function (DEC-02):**
1. resolve_decision to find it.
2. Query decision_constraints: `SELECT ... FROM decision_constraints WHERE decision_id = ?1 ORDER BY constraint_type`.
3. Query decision_topologies with JOIN: `SELECT dt.id, dt.topology_id, t.name, dt.added_at FROM decision_topologies dt JOIN topologies t ON dt.topology_id = t.id WHERE dt.decision_id = ?1 ORDER BY t.name`.
4. Text output (follow topology show pattern):
   ```
   Decision: {title}
     Status:          {status}
     Description:     {description}  (only if non-empty)
     Parent:          {parent_title} (only if parent_id set -- query parent decision title)
     ID:              {id}
     Created:         {created_at}
     Updated:         {updated_at}
     Closed:          {closed_at}    (only if set)
     Chosen topology: {topo_name}    (only if chosen_topology_id set)
     Rationale:       {rationale}    (only if set)

     Constraints:
       budget: max $1000.00
       noise:  max 32.0 dB
     (or "(none)")

     Considered topologies:
       sata-option (added 2026-02-07)
       nvme-option (added 2026-02-07)
     (or "(none)")
   ```
5. JSON output: Full decision object with nested "constraints" array and "considered_topologies" array.

**list() function (DEC-03):**
1. If status filter provided, validate it is one of: draft, open, decided, abandoned.
2. Query: `SELECT ... FROM decisions` with optional `WHERE status = ?1`, `ORDER BY updated_at DESC`.
3. Text output: List with status, title, and constraint/topology counts. Example:
   ```
     [draft]     NAS upgrade 2026    (2 constraints, 3 topologies)
     [decided]   SSD brand choice    (chose: nvme-option)
   ```
4. JSON output: Array of decision objects.

**update() function (DEC-04):**
1. resolve_decision. Check if "nothing to update" (no flags set).
2. If --title provided, check uniqueness (same pattern as node rename).
3. If --open flag, validate current status is "draft" and change to "open". (State machine: only draft -> open via this flag.)
4. Build after state, update in transaction with record_event.
5. Text/JSON output.

**constrain() function (DEC-05):**
1. resolve_decision.
2. Validate constraint_type is one of: "budget", "noise", "power", "rack_units". Bail with clear error if not.
3. Check if constraint already exists: `SELECT id FROM decision_constraints WHERE decision_id = ?1 AND constraint_type = ?2`. If exists, update it (delete old + insert new, or use REPLACE). Record before/after state.
4. Create DecisionConstraint::new(decision_id, type, max_value), insert with record_event.
5. Text: `Added constraint: {type} max {max}`. JSON: `{ "action": "constrained", ... }`.

**unconstrain() function (DEC-06):**
1. resolve_decision.
2. Find the constraint: `SELECT ... FROM decision_constraints WHERE decision_id = ?1 AND constraint_type = ?2`. Bail if not found.
3. Delete with record_event("decision_constraint.deleted", ...) and before_state.
4. Text/JSON output.

**consider() function (DEC-07):**
1. resolve_decision + resolve_topology(db, topology).
2. Check if already considered: `SELECT COUNT(*) FROM decision_topologies WHERE decision_id = ?1 AND topology_id = ?2`. Bail if already exists.
3. Create DecisionTopology::new(decision_id, topology_id), insert with record_event.
4. Text: `Considering topology '{topo_name}' for decision '{title}'`.

**unconsider() function (DEC-08):**
1. resolve_decision + resolve_topology.
2. Find the junction row. Bail if not found.
3. Delete with record_event, before_state.
4. Text/JSON output.
