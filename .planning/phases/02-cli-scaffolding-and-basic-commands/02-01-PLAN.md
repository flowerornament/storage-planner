  <name>Task 1: Create entity resolver module and update CLI dispatch</name>
  <files>src/core/resolve.rs, src/core/mod.rs, src/cli/mod.rs, src/cli/placement.rs</files>
  <action>
Create `src/core/resolve.rs` with the following functions:

1. **`validate_slug(name: &str) -> Result<()>`** — Validate that a name contains only alphanumeric chars, hyphens, and underscores. Error message: "Invalid name '{name}': must contain only alphanumeric characters, hyphens, and underscores".

2. **`resolve_active_topology(db: &Database, override_name: Option<&str>) -> Result<Topology>`** — If `override_name` is Some, resolve that topology by name-or-ID. Otherwise, find the topology where `is_active = 1`. Error if no active topology and no override given: "No active topology. Create one with 'sp topology create' or use --topology".

3. **`resolve_topology(db: &Database, name_or_id: &str) -> Result<Topology>`** — Try exact name match first (`WHERE name = ?1`). If no match, try UUID prefix match (`WHERE id LIKE ?1 || '%'`). Minimum prefix length: 4 chars. If multiple prefix matches, error listing the ambiguous matches. If no match at all, error "Topology '{name_or_id}' not found".

4. **`resolve_node(db: &Database, topology_id: &str, name_or_id: &str) -> Result<Node>`** — Same pattern: exact name match within topology, then UUID prefix. Error on ambiguity or not found.

5. **`resolve_volume(db: &Database, topology_id: &str, name_or_id: &str, node_hint: Option<&str>) -> Result<Volume>`** — Same pattern, but if name matches multiple volumes across different nodes (ambiguous), require `node_hint` to disambiguate. If `node_hint` is provided, resolve the node first, then filter volumes by that node_id. Error if ambiguous without `--node`: "Volume '{name}' exists on multiple nodes: {node_names}. Use --node to disambiguate."

6. **`resolve_dataset(db: &Database, topology_id: &str, name_or_id: &str) -> Result<Dataset>`** — Same name-or-ID pattern within topology.

Add `pub mod resolve;` to `src/core/mod.rs`.
