- `Show { name: String, #[arg(long)] topology: Option<String> }`
- `Remove { name: String, #[arg(long)] topology: Option<String> }`
- `Update { name: String, #[arg(long)] rename: Option<String>, #[arg(long)] role: Option<String>, #[arg(long)] location: Option<String>, #[arg(long)] bays: Option<i32>, #[arg(long)] interface_types: Option<String>, #[arg(long)] power_draw: Option<f64>, #[arg(long)] topology: Option<String> }`

**Update `run()` signature** to `pub fn run(cmd: NodeCommands, db: &mut Database, format: OutputFormat) -> Result<()>`.

**Implement each subcommand:**

`add`: Resolve active topology (with --topology override). Validate slug name. Create `Node::new(topology_id, name, role)`. Set optional fields (location, available_bays, interface_types, power_draw_watts). Insert in transaction. Record "node.created" event with after_state. Display: `Created node '{name}' (id: {id_prefix})` in text, full JSON in json mode.

`list`: Resolve active topology. Query all nodes `WHERE topology_id = ?1 ORDER BY name`. Text: one-liner per node `{name} [{role}] {location}`. Json: array of node objects.

`show`: Resolve active topology, resolve node by name-or-ID. Display node properties. Also query and display its volumes inline (name, capacity formatted via Capacity::from_bytes, filesystem). Text format:
```
Node: mac-mini
  ID:          a1b2c3d4...
  Role:        desktop
  Location:    office
  Bays:        0
  Interfaces:  usb3,thunderbolt4
  Power:       39W

  Volumes:
    ssd-1: 4.0TB apfs
    ssd-2: 4.0TB apfs
```
Json: node object with nested `volumes` array.

`remove`: Resolve active topology, resolve node. Count dependent volumes. Print warning: `Removing node '{name}' (and {n} volumes)`. Capture before_state. Delete in transaction. Record "node.deleted" event. Display confirmation.

`update`: Resolve active topology, resolve node. Capture before_state. Build UPDATE SET clause dynamically from provided Option fields. If rename provided, validate slug and check uniqueness within topology. Execute UPDATE. Record "node.updated" event with before/after state. Display confirmation.

Import: `use crate::core::db::Database; use crate::core::events::{record_event, EventSource}; use crate::core::models::{Node, Volume}; use crate::core::resolve::{resolve_active_topology, resolve_node, validate_slug}; use crate::core::specs::Capacity; use super::OutputFormat;`

Display: `Created volume '{name}' on node '{node_name}' (id: {id_prefix})`.

`list`: Resolve active topology. If `--node` provided, resolve node and filter by node_id. Otherwise list all volumes. Text: one-liner `{name} on {node_name}: {capacity_formatted} {filesystem}`. Json: array with node_name included.

```
  Usable:     3.6TB
  Filesystem: apfs
  RAID:       -
  Pool:       -
```
Json: full volume object.

`remove`: Resolve active topology, resolve volume. Count dependent placements and sync_regimes. Print warning about cascading deletes. Capture before_state. Delete in transaction. Record "volume.deleted" event.

`update`: Resolve active topology, resolve volume. Capture before_state. Build UPDATE SET clause dynamically. Parse capacity/usable if provided. Execute UPDATE. Record "volume.updated" event.

To look up the node name for display, query `SELECT name FROM nodes WHERE id = ?1` when needed.
