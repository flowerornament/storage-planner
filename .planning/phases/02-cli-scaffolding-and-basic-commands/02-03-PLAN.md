Replace the placeholder bodies in `placement.rs` with full implementation. Placements are immutable — no update command, just add and remove.

**The PlacementCommands enum was created in Plan 01.** Keep the same structure. Implement the `run()` function.

**Implement each subcommand:**

`add`: Resolve active topology. Resolve dataset by name-or-ID. Resolve volume by name-or-ID (with --node disambiguation). Check that this placement doesn't already exist (dataset_id + volume_id unique constraint). Create `Placement::new(topology_id, dataset_id, volume_id)`. Set role and priority from args. Insert in transaction. Record "placement.created" event with after_state. Display: `Placed dataset '{dataset_name}' on volume '{volume_name}' [{role}]` in text mode.

`list`: Resolve active topology. Query all placements within topology, JOINed with datasets and volumes (and nodes for volume's node name):
```sql
SELECT p.*, d.name as dataset_name, v.name as volume_name, n.name as node_name
FROM placements p
JOIN datasets d ON p.dataset_id = d.id
JOIN volumes v ON p.volume_id = v.id
JOIN nodes n ON v.node_id = n.id
WHERE p.topology_id = ?1
ORDER BY d.name, p.priority
```
Text: one-liner `{dataset_name} -> {volume_name} on {node_name} [{role}, priority: {priority}]`. Json: array with all fields plus resolved names.

`remove`: Resolve active topology. Resolve dataset and volume. Find placement by dataset_id + volume_id. Capture before_state. Delete in transaction. Record "placement.deleted" event. Display confirmation.

Import: `use crate::core::db::Database; use crate::core::events::{record_event, EventSource}; use crate::core::models::Placement; use crate::core::resolve::{resolve_active_topology, resolve_dataset, resolve_volume}; use super::OutputFormat;`
