- `Remove { name: String, #[arg(long)] topology: Option<String> }` — same identifier format

**Update `run()` signature** to `pub fn run(cmd: LinkCommands, db: &mut Database, format: OutputFormat) -> Result<()>`.

**Implement each subcommand:**

`add`: Resolve active topology. Resolve source node (`from`) and target node (`to`) by name-or-ID. Check for existing link between same node pair (same direction). Parse bandwidth using `Speed::parse()` if provided — store as `bytes_per_sec` (i64). Create `Link::new(topology_id, source_node_id, target_node_id, connection_type)`. Set optional fields. Insert in transaction. Record "link.created" event.

Auto-name for display: `{source_node_name}--{target_node_name}`. Display: `Created link '{source}--{target}' ({connection_type}, {bandwidth_formatted})` or `Created link '{source}--{target}' ({connection_type})` if no bandwidth. Include id prefix.

`list`: Resolve active topology. Query all links within topology. For each link, look up source and target node names via JOIN:
```sql
SELECT l.*, n1.name as source_name, n2.name as target_name
FROM links l
JOIN nodes n1 ON l.source_node_id = n1.id
JOIN nodes n2 ON l.target_node_id = n2.id
WHERE l.topology_id = ?1
ORDER BY n1.name, n2.name
```
Text: `{source_name} -> {target_name} [{connection_type}] {bandwidth_formatted}`. Json: array with resolved names.

`show`: Resolve active topology. Parse the `name` argument as `{source}--{target}`. Split on `--`, resolve both node names, find the link by source_node_id + target_node_id within topology. Display all fields. Text:
```
Link: mac-mini -> nas
  ID:          a1b2c3d4...
  Type:        lan
  Bandwidth:   1.0GB/s
  Latency:     1ms
  Metered:     no
  Cost/GB:     -
```
Use `Speed { bytes_per_sec }.to_string()` for bandwidth display. If bandwidth is None, show "-". Json: full link object with resolved names.

`remove`: Resolve active topology. Parse name, resolve nodes, find link. Count dependent sync_regimes that use volumes on these nodes. Print warning if any. Delete in transaction. Record "link.deleted" event.

Import: `use crate::core::db::Database; use crate::core::events::{record_event, EventSource}; use crate::core::models::Link; use crate::core::resolve::{resolve_active_topology, resolve_node}; use crate::core::specs::Speed; use super::OutputFormat;`

`list`: Resolve active topology. Query all sync_regimes with JOINs to resolve names:

```sql
SELECT s.*, d.name as dataset_name,
       sv.name as source_volume_name, sn.name as source_node_name,
       tv.name as target_volume_name, tn.name as target_node_name
FROM sync_regimes s
JOIN datasets d ON s.dataset_id = d.id
JOIN volumes sv ON s.source_volume_id = sv.id
JOIN nodes sn ON sv.node_id = sn.id
JOIN volumes tv ON s.target_volume_id = tv.id
JOIN nodes tn ON tv.node_id = tn.id
WHERE s.topology_id = ?1
ORDER BY s.name
```
Text: `{name}: {dataset_name} {source_vol}({source_node}) -> {target_vol}({target_node}) [{sync_type}, {schedule}]`. Json: array with all fields plus resolved names.
