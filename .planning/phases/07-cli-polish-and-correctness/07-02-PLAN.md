  <action>
Add pre-insert uniqueness checks following the exact pattern already used by `decision create` (see `src/cli/decision.rs` line ~202-210). The pattern is: query SELECT COUNT(*) before the transaction, bail with friendly message if count > 0.

**1. topology.rs -- `create()` function (line ~179):**

After `validate_slug(name)?;` and before `let topo = Topology::new(name, description);`, add:
```rust
let existing: i64 = db.conn().query_row(
    "SELECT COUNT(*) FROM topologies WHERE name = ?1",
    params![name],
    |row| row.get(0),
)?;
if existing > 0 {
    bail!("Topology '{}' already exists", name);
}
```

**2. node.rs -- `add()` function (line ~198):**

After `let topo = resolve_active_topology(db, topology_override)?;` and before `let mut node = Node::new(...)`, add:
```rust
let existing: i64 = db.conn().query_row(
    "SELECT COUNT(*) FROM nodes WHERE topology_id = ?1 AND name = ?2",
    params![topo.id, name],
    |row| row.get(0),
)?;
if existing > 0 {
    bail!("Node '{}' already exists in topology '{}'", name, topo.name);
}
```

**3. volume.rs -- `add()` function (line ~197):**

After `let node = resolve_node(db, &topo.id, node_name)?;` and before `let mut vol = Volume::new(...)`, add:
```rust
let existing: i64 = db.conn().query_row(
    "SELECT COUNT(*) FROM volumes WHERE topology_id = ?1 AND node_id = ?2 AND name = ?3",
    params![topo.id, node.id, name],
    |row| row.get(0),
)?;
if existing > 0 {
    bail!("Volume '{}' already exists on node '{}'", name, node.name);
}
```

**4. dataset.rs -- `add()` function (line ~187):**

After `let topo = resolve_active_topology(db, topology_override)?;` and before `let mut dataset = Dataset::new(...)`, add:
```rust
let existing: i64 = db.conn().query_row(
    "SELECT COUNT(*) FROM datasets WHERE topology_id = ?1 AND name = ?2",
    params![topo.id, name],
    |row| row.get(0),
)?;

    bail!("Dataset '{}' already exists in topology '{}'", name, topo.name);

```

**5. catalog.rs -- `add()` function (line ~141):**

After the specs JSON parsing block and before `let mut item = CatalogItem::new(name, category);`, add:
```rust
let existing: i64 = db.conn().query_row(
    "SELECT COUNT(*) FROM catalog_items WHERE name = ?1",
    params![name],
    |row| row.get(0),
)?;
if existing > 0 {
    bail!("Catalog item '{}' already exists", name);
}
```

**Key constraint from research (Pitfall 5):** Only pre-check for UNIQUE violations, not FK violations. The pre-check approach avoids the risk of accidentally catching FK constraint errors and turning them into misleading "already exists" messages.

**Note:** The `placement add`, `link add`, `sync add`, and `decision create` commands already have pre-checks. Do NOT modify those -- they are already correct.
